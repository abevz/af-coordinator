# Design

Release metadata uses the public GitHub releases API; the selected tag supplies CHANGELOG.md. Strict semantic comparison excludes drafts and prereleases unless --prerelease or the installed version is a prerelease. Source/dev builds require a release version for checks and do not refresh.

Cache and notice ledger: $XDG_STATE_HOME/dibs/update.json (default ~/.local/state/dibs/update.json), separate from coordinator storage. The daemon runs a cancellable refresh goroutine, bounded by an 8-second network context. Persisted last attempt enforces 24 hours across restarts and offline failures. CLI commands never refresh except explicit update; notices use nonblocking file locks and atomic cache writes. Cache is keyed by installed version/channel.

Publication preserves BINDIR/dibs, BINDIR/dibsd, BINDIR/dibs-mcp. Hidden BINDIR/.dibs-update holds staging, generations, a current pointer and exclusive update lock. Each new generation records its predecessor before publication, committing binaries and rollback metadata together. Initial adoption copies the existing three files into one generation, then converts public paths to symlinks pointing through the same current pointer without changing their contents. A single atomic current-symlink rename publishes a verified generation or restores previous binaries. Files and directory metadata are synced before commit; failed downloads/checksums cannot publish, and a failed subsequent upgrade preserves the existing rollback target. Rollback after restart failure is available without network. Existing independent symlinks and Homebrew Cellar/receipt-managed installations are refused; use that installation manager. The existing public license path is retained; the verified release license also stays in its generation. No DB/socket/service configuration is rewritten.

A breaking-change prompt precedes downloads. --yes authorizes that prompt only, never restart. Restart and version verification use injected callbacks; production callbacks restart the existing systemd/LaunchAgent unit only on explicit approval. A failed restart leaves the selected binaries and previous generation available for explicit rollback.
